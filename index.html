ವಿಡಿಯೋ YouTube ಮೂಲಕ ಪ್ಲೇ ಆಗುತ್ತದೆ. ಕೆಲವು ವಿಡಿಯೋಗಳನ್ನು ಮಾಲೀಕರು embed ಮಾಡಲು ಅನುಮತಿಸದೇ ಇರಬಹುದು.

ಪೂರ್ಣ ಸಿನಿಮಾ

ಈಗ ಕ್ಯಾಟಲಾಗ್ ಮತ್ತು ಟ್ರೈಲರ್‌ಗಳು ಸಿದ್ಧವಾಗುತ್ತವೆ. ಪೂರ್ಣ ಸಿನಿಮಾ ಪ್ಲೇ ಮಾಡಲು ಹಕ್ಕುದಾರರು ಅನುಮತಿ ನೀಡಿರುವ ನೇರ ವಿಡಿಯೋ URL ಅಥವಾ ಅಧಿಕೃತ embed ಬೇಕು. TMDB API ಕೀ ಸ್ವತಃ ಪೂರ್ಣ ಸಿನಿಮಾ ನೀಡುವುದಿಲ್ಲ.

ಈ ಉತ್ಪನ್ನವು TMDB API ಬಳಸುತ್ತದೆ; TMDBಯಿಂದ ಅನುಮೋದಿಸಲ್ಪಟ್ಟಿಲ್ಲ ಅಥವಾ ಪ್ರಮಾಣೀಕರಿಸಲ್ಪಟ್ಟಿಲ್ಲ. ಸಿನಿಮಾ ಮಾಹಿತಿ ಮತ್ತು ಚಿತ್ರಗಳ ಮೂಲ: TMDB.
